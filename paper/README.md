# Overleaf manuscript sources removed

The ICBC 2027 Overleaf manuscript (`main.tex`) and bibliography (`references.bib`) were removed from this public GitHub repository's current branch at the author's request.

The Python research code remains in `prototype/` and `simulator/`. The original Overleaf project, if stored separately in Overleaf, has not been modified.

**Important:** Older Git commits may still expose the deleted source files. Removing files from the current branch is not a complete historical purge.
